# Архитектура и принятые решения

Поток запроса: HTTP → проверка формата → сервис → репозиторий SQLite → публичная модель → JSON.
Обработчик отвечает за HTTP-статусы; сервис — за бизнес-правила; репозиторий — за параметры SQL, транзакции и данные.
Объекты создаются в точке запуска, без глобального изменяемого состояния и без общего курсора.

## Данные

```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    tags TEXT NOT NULL,
    password_hash TEXT
);
```

`tags` — JSON-массив строк, декодируется в Python list / Go []string. `password_hash` не выбирается публичными запросами.
Имена не уникальны: изменение этой семантики исходник не требовал.
Файл создаётся автоматически в `DB_PATH`, с общей схемой двух реализаций.
Исходные `users.db` и `test.db` не предоставлены; существующие данные не мигрируются и не переписываются.

## Параллельная работа

Python: SQLite connection открывается на операцию, контекст управляет commit/rollback, finally закрывает connection.
Go: `database/sql`, ограничение пула одной connection предотвращает конкуренцию собственных SQLite-записей.
Обе реализации используют WAL и busy timeout 5000 ms. Контексты Go передаются до SQL-запросов.
Активность хранится в экземпляре сервиса, операция удаления дубликата/добавления/ограничения размера защищена одной блокировкой.
Наружу возвращается копия списка, поэтому вызывающий код не может изменить состояние.
В нескольких экземплярах сервера активность будет разной: для масштабирования перенесите её в общее хранилище.

## Фоновые задачи и остановка

`/slow` сохраняет учебный контракт 202. Работа ограничена двумя исполнителями; нет неограниченной очереди потоков/горутин.
При занятости — 503 с Retry-After. Число итераций фиксировано, пользователь не управляет нагрузкой.
Go получает SIGINT/SIGTERM, прекращает приём запросов, ждёт текущие HTTP-запросы до 10 s, отменяет фоновые задачи и закрывает БД.
В Python используется Waitress и короткие daemon-потоки; долговечная очередь задач здесь не реализована.

## Совместимость с уроком

Канонический путь создания `/adduser`, старый `/adducer` сохранён как deprecated alias.
GET и POST `/activate/{id}` поддерживаются как в уроке; GET имеет побочный эффект, поэтому рекомендован POST.
`/wrong` возвращает фиксированный учебный JSON 500 без настоящей паники/деления на ноль.
Маршруты `/activate`, `/slow`, `/wrong` отсутствовали в обрезанном локальном api.py и восстановлены по тексту урока.
`is_admin` и расчёт суммы квадратов также добавлены как описанные в уроке вспомогательные функции, а не как обнаруженные в локальном utils.py.

## Контракт и сборка

`scripts/generate_openapi.py` — единственный источник схем. YAML/JSON версионируются, проверяются валидатором и встроены в Go через `go:embed`.
Изменение схем требует повторной генерации и сборки бинарного файла.
Go-модули фиксируются в go.mod/go.sum, Python-зависимости — в requirements*.txt.
Образ собирается через стадии base → test → build → scratch. Финальная стадия зависит от test: образ не соберётся при ошибках тестов.
Pure-Go SQLite допускает CGO_ENABLED=0 и запуск без libc. В финальном образе только статический бинарный файл и writable volume `/data`.

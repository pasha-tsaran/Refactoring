User API

Контракт OpenAPI 3.1: YAML · JSON. Импортируйте файл в Swagger Editor, Postman или Insomnia. Эта страница работает без внешних ресурсов.

Метод и путьДействие
GET /healthПроверить HTTP и SQLite
POST /adduserСоздать: {"name":"Анна","tags":["student"]}
POST /adducerУстаревший совместимый путь создания
GET /user/{id}Получить пользователя
GET, POST /activate/{id}Активировать существующего пользователя
GET /slowЗапланировать фоновую задачу: 202; при занятости: 503
GET /wrongУчебный маршрут: ожидаемый ответ 500

Список активности хранится в памяти одного процесса (до 50 уникальных ID). Пользователи и хеши паролей хранятся в SQLite. Авторизации в учебном API нет; для внешнего доступа используйте защищённый шлюз.
